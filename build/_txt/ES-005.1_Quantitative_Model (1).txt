Section 1 — Reference Strength (the score→kg decoder)
Score maps to a reference 1RM-equivalent on the canonical exercise (difficulty_factor = 1.0) via a strictly increasing exponential. Exponential, not linear, so a fixed score step is a fixed PERCENTAGE of load — matching how strength actually scales. Strictly increasing guarantees the closed-form inverse §8 depends on.
ReferenceStrength(S) = A · e^(k·S)        A = 40.0 kg,  k = 0.016227
Constants pinned to ES-005: S=64 → 113 kg, and S=0 → 40 kg (beginner floor). Inverse:
S(RM1) = ln(RM1 / A) / k

Section 2 — Exercise projection & the rep model
Capability strength projects to a specific exercise by difficulty_factor, then Epley converts (load, RM1) to reps-to-failure. Epley is chosen because it is cleanly invertible in all three directions the loop needs.
RM1_exercise   = ReferenceStrength(S) · difficulty_factor
reps_to_failure(L)   = (RM1_exercise / L − 1) · 30        [forward / predict]
load_for_reps(r)     = RM1_exercise / (1 + r/30)         [recommend]
RM1_observed(L, r)   = L · (1 + r/30)                    [learn / inverse]
Check: bench (df 1.0), S=64 → RM1 113. reps_to_failure(82.5) = (113/82.5 − 1)·30 = 11.1. Matches ES-005’s example of 11.
Section 3 — Prediction is reps-to-failure; prescription is target reps
These are different scales (ES-005 §4 is correct). The learning signal compares against reps-to-failure; the athlete is prescribed fewer reps, leaving reps-in-reserve (RIR).
predicted_reps_to_failure = reps_to_failure(L)
target_reps               = predicted_reps_to_failure − RIR     (RIR ≈ 2–3, strategy-set)
prediction_error          = actual_reps − predicted_reps_to_failure   → must converge to 0
Section 4 — The convergence hazard (effort bias)
prediction_error converges to zero ONLY if actual_reps reflects true reps-to-failure. Two biases distort this: (a) calibration deliberately under-predicts; (b) athletes stop short of true failure. They push error in opposite directions, so the system converges to wherever they cancel — not necessarily zero, and the cancellation point drifts as confidence (hence the discount) changes.
Mitigation: track effort separately from accuracy.
Section 5 — Score update (stable Bayesian blend)
Every completed set yields an observed score via the §2 inverse. The capability score is a precision-weighted blend. Critically, the weight DECREASES with surprise (quality), so a wild observation cannot hijack the estimate — this removes the positive-feedback instability latent in ES-005 §9.
RM1_obs = actual_weight · (1 + actual_reps/30)        // uses ACTUAL weight (override-safe)
S_obs   = ln(RM1_obs / A) / k

w_i     = decay(Δt_i) · quality_i
quality_i = (prediction_confidence_i/100) · error_class_weight_i
   error_class_weight:  |err|≤1 → 1.0 ,  ≤3 → 0.6 ,  >3 → 0.3

Σw-form (precision accumulator):
  Σw_new = Σw_old + w_i
  S_new  = (Σw_old·S_old + w_i·S_obs) / Σw_new
Surprise (large |error|) lowers quality → lowers the weight on S_obs → the score moves little. Surprise is instead routed to confidence (§6), where it lowers certainty. This is the resolution of the signal-strength-vs-quality conflict: quality drives the SCORE, signal-strength drives CONFIDENCE.
Section 6 — Confidence (three formulas, correct direction)
Capability confidence is a saturating function of accumulated precision. Prediction confidence is DERIVED from capability confidence and recent accuracy. Global confidence is an AGGREGATE of capability confidences. Aggregation and derivation are distinct — global is not computed from prediction.
c_cap   = 100 · (1 − e^(−Σw / 8))                 // 8 effective obs ≈ 63% conf; floor 10 at seed
stability = max(0.2, 1 − mean(recent |error|)/5)
c_pred  = c_cap · stability                       // derivation
c_global = Σ_j(evidence_count_j · c_cap,j) / Σ_j evidence_count_j   // aggregation over 7 caps
Because decay shrinks Σw over idle time, confidence falls when an athlete stops training — the “recent evidence matters” principle applied to certainty. Calibration ends when c_global ≥ 70 (a COMPUTED quantity, replacing the standalone boolean). The explicit “all capabilities observed” check is kept; the raw “≥50 observations” rule is redundant under this formula and dropped.
Section 7 — Recommendation operator (discount, floor, guard)
Order of operations matters: discounting then flooring can stack into a net decrease near plate boundaries. The operator applies a confidence-scaled discount, floors ONCE to equipment granularity, then applies a progression guard that forbids a silent decrease unless the evidence path itself called DECREASE_LOAD.
safety_discount = 1 − 0.12 · (1 − c_pred/100)        // c_pred=20 → ×0.904 ; c_pred=90 → ×0.988
L_ideal = load_for_reps(target_reps + RIR)
L = floor( L_ideal · safety_discount / incr ) · incr   // incr: 2.5kg barbell / stack for machine
if L below last_accepted_load AND evidence ≠ DECREASE:  L = last_accepted_load   // progression guard
The guard converts the dangerous double-conservatism (which produced a load DECREASE for a ready athlete in testing) into a hold. A genuine decrease still flows when the Decision Engine emits DECREASE_LOAD on persistent negative evidence.
Section 8 — Cohort priors & the bodyweight residual
Onboarding already collects sex and age; the prior should use them. Apply a multiplier to the reference strength PRIOR only (observations override within ~5 sets).

Final Principle (Principle #44, made literal)
Every recommendation is now reconstructable as an arithmetic chain: score → e^(kS) → ×df → Epley → discount → floor → guard. Every learning step is its exact inverse: actual → Epley⁻¹ → ln/k → precision-weighted blend. No step is a black box; every constant above is pinned to ES-005’s stated anchors.
