# Hush Motion System — Phase 1 + Pilot (4 movement families)

**Status 2026-07-07:** bench benchmark + the three-movement pilot (Barbell Back Squat, Barbell Row,
Lat Pulldown) are built and green, and the figure has been through the **embodiment rebuild** —
the Duotone Athlete skin v2 (filled trunk silhouette, tapered limbs, one canonical anthropometry
in `src/motion/anthro.ts`, true-scale ghost plates in `src/motion/kit.ts`). Same FormSpecs, same
validator; every prior test passes unmodified. Live loops rendered from the compiled core;
committed snapshots below (`*_demo.gif`, `*_validation.txt`). Interactive review page is
generated by `tools/motion-harness/reviewpage.js`.


The exercise demonstration system. A 2D skeletal figure, defined in code, performs each movement
from a `FormSpec` (the canonical definition of the exercise), rendered live in the app. No video
files, no external tools, no hosting — pure TypeScript + `react-native-svg`, validated by CI.

See `docs/canonical/MOTION_FORM_STANDARD_V1.md` for the normative form standard and the full
category model (3 mechanics, 20 templates, all 60 catalog exercises).

## Where it lives

```
src/motion/
  types.ts        FormSpec, Pose, Primitive, Rig — the contracts
  geometry.ts     vectors, two-bone IK, joint-angle measurement, easing
  timeline.ts     canonical tempo → range-of-motion fraction (2 identical reps)
  formspec.ts     validate(rig) — asserts every predicate across the loop (the CI teeth)
  anthro.ts       the canonical athlete: one segment-length table shared by every rig
  kit.ts          shared equipment: true-scale ghost plates, bar-path ticks, ground shadow
  skin.ts         the Duotone Athlete skin v2 (trunk silhouette + tapered limbs, one renderer)
  palette.ts      token → hex (mirrors src/design/tokens.ts)
  frame.ts        composes scene + equipment + figure into Primitive[]
  library/        one file per exercise: bbBenchPress · bbBackSquat · bbRow · latPulldown
  registry.ts     EXERCISE_MOTION map + exerciseMotion(id)
  render/MotionFigure.tsx   the React Native renderer (consumes the same Primitive[])
```

Two authoring patterns cover all four (and, per the standard, all 60): **Mechanic A** (implement
travels, body anchored — bench, row, pulldown) drives only the bar height and solves the arm by
two-bone IK from the fixed shoulder; **Mechanic B** (the body travels — squat) drives the leg
angles with fixed segment lengths and *solves the torso lean* so the bar stays over the mid-foot,
making the vertical bar path true by geometry rather than a tuned number.

`components/FormMedia.tsx` prefers motion → then the existing video seam → then the static
silhouette, so an exercise lights up the moment its rig is added, with no other change.

## Visual QC (filmstrip / hero PNGs, headless)

`tools/motion-harness/filmstrip.js` and `hero.js` render any rig to a static SVG grid that headless
Chrome screenshots to PNG — the loop used to author and eyeball each movement:

```
npx tsc -p tsconfig.harness.json
node tools/motion-harness/hero.js bb_back_squat out.html "0,0.5,1"
chrome --headless --screenshot=out.png --window-size=1000,760 file://<abs>/out.html
```

## Regenerating the review harness (GIF, filmstrip, live page)

The harness renders the **exact compiled source** the app ships and CI validates — zero duplicated
math. Two steps (PowerShell or bash):

```
# 1. compile the pure motion core to Node-runnable JS
npx tsc -p tsconfig.harness.json

# 2. emit the review surfaces (benchmark.html, gifpage.html, frames.json, validation.txt)
node tools/motion-harness/emit.js <output-dir> bb_bench_press
```

`benchmark.html` is a self-contained review page (live looping figure + filmstrip + validation).
`gifpage.html` encodes an animated GIF in-browser; open it in a browser (or headless with
`--dump-dom`) and pull the `GIFB64:…:END` payload. The committed `bench_press_benchmark.gif` and
`bench_press_validation.txt` here are snapshots of that output.

## The guarantee

`__tests__/motion/bbBenchPress.test.ts` and `__tests__/motion/pilot.test.ts` run the FormSpec
validator on all four rigs on every commit, and also prove the validator has teeth — deliberately
broken rigs (lifted hips, a curved bar path, a partial press, a lifted heel, a swinging torso, a
bar bounced past the collarbone) must fail. The demonstration can never silently contradict Hush's
cues.
