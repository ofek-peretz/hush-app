Readable from the bar. Felt like a coach.
THE SET complete → THE DOT LANDS ON THE BAND inside → rest  ·  broke it → CORRECTION one breath → REST
No separate “recorded” screen. Completing a set drops its dot onto the band — that is the receipt. Lands inside: rest begins directly, dot already on the gauge. Breaks the band: the correction takes the screen for one breath — the gauge stays exactly where it was, only the number gives way beneath it — then settles into rest. One shared element, three beats, zero taps.
